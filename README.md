# peopleflow-hrms
PeopleFlow HRMS is a web-based Human Resource Management System developed using C++, SQLite, HTML, CSS, and JavaScript. The project is designed to simplify employee management, attendance tracking, leave management, and HR operations through an interactive dashboard.  It features role-based access control for Admin, HR, and Employees, ensuring users can access functions according to their assigned roles. The system uses SQLite for persistent data storage and provides a user-friendly interface for managing employee records and monitoring workforce information.
